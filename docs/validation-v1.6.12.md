# v1.6.12 动画与下拉交互验证

验证环境：Windows、Python 3.11.8、PySide6 6.12.0；源码及安装器版本均为1.6.12。验证日期2026-11-21至22。本轮在已有未提交改动之上继续修复，未提交Git、未推送GitHub或更新节点。

## 改动与用户可见行为

- 下拉、卡片、预览胶囊和任务进度共用按真实经过时间计算的阻尼解。展开、收起、选择及反馈的角频率分别为24、32、36、26 rad/s，阻尼比均为1；展开平稳到位，收起较快，不再来回弹跳。
- 反向从最后已显示的位置及速度接续。菜单原生窗口及列表正文大小在一轮展开期间固定，只改变裁切可见区域；卡片正文保持自然尺寸。卡片首次展开时的同步宽度重排不会使动画提前结束。
- 预览胶囊不再被关联单选按钮的同步回调打断；显式不带动画的状态同步仍可取消旧动画并精确落位。
- 任务窗口的等待光带自动往返。自绘及原生进度控件按实际时间更新，纵向光带沿纵向轨道运动；已知进度平滑到达新目标，控件隐藏、禁用或完成后停止计时。

## 下拉菜单缺陷与修复证据

| 原问题 | 修复及验证结果 |
|---|---|
| 关闭动画中连点其他行或按Enter会多次激活；Esc后仍可提交 | 在回调和收起动画之前锁定该会话；重复提交及取消后输入的回归通过 |
| Qt.Popup抢占鼠标，外部按钮或另一个下拉框首次点击不生效 | 改用不抢键盘焦点的临时工具窗口；Windows实际鼠标输入验证首次外部点击、A→B一次切换均通过 |
| 清空、重置或替换模型后保留旧菜单，旧行可选中新模型的无关条目 | 模型结构改变前关闭会话；模型/根/列替换及外部选值后关闭旧预览，重新打开使用当前模型 |
| 用户回调删除前面的行后发送旧行号；高亮信号重复 | 按持久条目身份检查激活，回调删除第0行后原第2项正确激活为第1行；替换模型不发送失效激活；鼠标高亮和确认各发送一次 |
| 键盘、Tab焦点及控件移动后位置失效 | 控件保留键盘焦点，方向/Home/End/文字检索预览，Enter/Space确认，Esc/Alt+↑取消，Tab/Shift+Tab退出；滚动、移动、隐藏或禁用时关闭旧菜单 |

## Windows实际输入与主窗口集成

`_tmp/qa_v1612.py`通过Win32鼠标输入操作本次创建的测试窗口。每次输入前使用WindowFromPoint和父子关系验证目标属于自己的可见窗口；未点击或关闭用户的其他窗口，结束时恢复原鼠标位置及前台窗口。

实测首次点击外部按钮、单击从A菜单切换到B菜单、实际点击第2行只激活一次并保留原控件键盘焦点均通过。此前审计仅有Qt/QTest输入，本轮补充了系统鼠标路由验证；结论限于本机、本次测试位置与窗口组合。

主窗口中实测四次快速往返胶囊选择、卡片反向收展、菜单固定正文和原生窗口几何，以及实际TaskWindow的等待/已知进度/完成态。底部同时收起两张卡片时滚动值保持1310，上方标题屏幕坐标保持稳定。

构建使用`package_release.ps1 -SkipNode`，生成本地单文件、便携文件夹ZIP和安装包；未推送更新节点。单文件构建113.3s，文件夹构建66.3s；完整文件夹含284个载荷文件。文档补录通过`-DocsOnly -SkipNode`刷新，不改变程序二进制。

- 单文件及文件夹`--selftest`分别4.5s、1.7s返回0；实际导入MODNet内核、定位捆绑权重、处理示例头像并输出单张与排版JPEG。
- Windows原生启动：文件夹2.3s、单文件3.4s显示Qt主窗口；两者均可通过WM_CLOSE正常退出，未出现Tk启动窗，未遗留此次运行的_MEI解包目录。这里的启动时间仅是本机此次采样。
- 安装版完成静默安装→安装位置运行自检→卸载，全部返回0；安装目录、卸载注册项和两个开始菜单快捷方式均创建并清理。测试使用项目盘临时目录，遇到用户已有安装注册项或快捷方式会中止，未覆盖用户安装。
- 三种形态的当前1.6.12冻结自检均通过5步、各生成两张JPEG；另以Pillow读回，确认一寸照片295×413 px、JPEG DPI约300，全部图像可正常解码。
- 交付核验**23项通过**，包括构建前后75个源码/打包文件摘要不变、三个程序与dist完全一致、13份公开文档/媒体在交付目录及ZIP中与源码一致、309个ZIP条目路径安全、规格数据及MODNet权重摘要一致，以及两个冻结分析表包含新的motion等模块。
- `成品软件/SHA256SUMS.txt`列出17个受管理交付文件并逐一读回校验。交付文件夹中已有的输出目录及设置保留；只清理本次测试创建的标记，不删除用户输出。

C盘空闲量在两次自检期间变化-0.4/-1.8MB；空闲量受其他进程影响，该数据不构成“系统盘零写入”的证明。完整在线更新、打印或受理结论不属于以上打包验收。

## 范围与限制

本轮覆盖应用中已有的卡片、下拉、分段胶囊和进度动效。预览缩放/拖动仍直接响应用户输入；系统文件对话框及安装器动效由系统控制。实际鼠标验证没有覆盖所有DPI、多显示器、辅助功能或系统主题组合，也不作固定帧率保证。

未重新实证整套在线更新/UAC/中断回滚、资源管理器跨权限拖放、真实打印或报名系统受理。照片尺寸来源及历史口径限制继续见[尺寸复核](research/photo-size-sources.md)和[v1.6.7处理与规格验证](validation-v1.6.7.md)。
