# v1.6.9 动画与导出验证

验证日期：2026-11-20。环境：本机 Windows / Python 3.11 / PySide6；界面规格及此前 v1.6.7 的图像处理修复继续保留。本页记录本轮证据，不代替打印、受理审核或在线更新验收。

## 动画修复与回归

- 使用有阻尼的连续运动模型。快速反向保留当前位置和速度，动画初始化时屏蔽旧插值信号；展开仅保留小幅回弹，关闭平滑减速。
- 正文尺寸仅在内容或宽度改变时测量，逐帧只修改可见高度。标题点击不再遍历测量整列宽度；多个卡片使用 Qt 动画时钟独立运行。
- 新增8项卡片回归：位置/速度连续、无旧插值跳变、逐帧不重测正文、相同目标不重启、31次快速反向后的有限数值及精确终点、动态正文中途改高、真实事件循环的双卡片动作、隐藏时正确停止。部分测试合并检查多种条件。
- Windows 原生窗口使用真实标题点击，两个卡片交错动作并连续反向20次。点击同步阶段最大高度跳变为0像素；两卡片最后均达到精确终点。
- 原生事件循环采样47个间隔，95分位31.28ms、最大31.69ms；这是含QTest等待的本机测量，不是全机型60fps保证。GIF是另一次实际窗口抓帧，编码在抓帧结束后进行。

## 导出行为

- 文件名包含原图名、中文规格名、稳定ID、毫米尺寸和背景；排版再加相纸信息。文件名处理Windows非法字符、设备名、尾随点空格及UTF-16长度。
- 独占创建新路径，遇到现有文件/目录时改用 `_2`、`_3` 等递增后缀。失败仅清理本次预留文件，不触碰已有结果。此策略用于GUI；通用编码器与CLI的原有语义未改变。
- 导出成功后先请求打开实际输出目录，再显示结果，一次导出动作只打开一次目录。目录打开失败保留文件并提示；部分成功也列出已保存路径并打开所在目录。
- 专项测试执行真实JPEG编码、DPI/尺寸回读及文件字节检查；覆盖一寸/二寸/重复一寸、同时导出单张与排版、24个并发预留、已有文件不变、失败清理、打开目录失败、部分成功和无结果不打开目录。
- 原生UI实际运行MODNet，依次导出295×413一寸、413×626二寸、重复一寸三份JPEG，前两份保持不变。另实际调用Windows目录打开接口，确认标题含“导出验证-v1.6.9”的资源管理器窗口出现。
