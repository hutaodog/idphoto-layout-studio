# v1.6.10 下拉、收起与连续曲率验证

验证日期：2026-11-20。本机 Windows / Python 3.11 / PySide6。此前单张处理、原底色、导出防覆盖等功能保留；本轮仅本地构建，未向在线更新节点发布。

## 收起时上方跳动的原因与修复

原先在滚动列底部收起，QScrollArea 会随着内容最小高度缩短而强制夹紧滚动值，造成整列上移。正文输入框仍持焦点时，最终隐藏还会将焦点转到后续卡片，触发另一次自动滚动。

现在以可见标题为屏幕锚点，利用现有底部弹性区域保留当前视口所需空间；上方离屏内容收起时，按可见标题位移补偿滚动，避免留下不可达的空视口。用户滚轮滚动或重新展开时自然释放/吸收尾部空间。收起前清除正文中的焦点，避免最终隐藏时再发生跨卡滚动。布局先更新自然最小尺寸，再测标题，消除多轮开合累计漂移。

新增11项真实MainWindow事件循环回归：顶部/中部/近底部/底部、双卡收起、输入框持焦点、首卡终帧隐藏、视口上方卡片、滚轮释放、动画中滚轮及快速反向重复开合。测量实际屏幕坐标、滚动值和正文几何，不以动画内部数字代替屏幕证据。

## 下拉弹簧与连续曲率

- 分类、相纸、裁切线和DPI下拉使用固定原生窗口、固定自然尺寸列表，仅改变可见区域。展开轻微回弹，反向接续已显示的高度与速度；空间不足时向上展开，列表行的屏幕锚点保持不动。
- 鼠标、方向键、回车确认、Esc取消、禁用项、空列表、所属窗口隐藏等有实际Qt事件循环覆盖；选择信号只触发一次。
- 应用可控的窗口、卡片、按钮、输入框、下拉项、分段切换、菜单选中、进度及应用内提示框使用同一连续曲线路径。每角由两段三次Bezier组成，直边连接处曲率为零，中点二阶导数匹配；不是只增大QSS圆角半径。
- 保留原有盒尺寸、字体和状态颜色；圆形指示点、单选与滑块圆头保留圆形。系统文件选择器、资源管理器、安装器不由应用重新绘制。
- 样式更新在Qt样式事件返回后执行，并在触发重新polish前保存绘制对象，避免创建窗口及动态换色时重入。完整窗口回归包含此集成路径。
