# v1.6.11 连续圆角、胶囊与原生窗口验证

验证日期：2026-11-20。本机 Windows 11 build 26300、PySide6 6.12、DPR 1。保留既有处理、动画和导出功能，本轮仅生成本地构建，未向更新节点或GitHub发布。

## 外圆角的原因与修复

v1.6.10将DWM圆角关闭，尝试用`QWidget.setMask()`裁切SCA亚克力窗口。独立原生探针显示：Qt窗口区域确实变成了复杂圆角区域（`GetWindowRgn=3`，区域外点不命中），但SCA仍按矩形合成背景。屏幕角落从纯色底`(160, 0, 96)`变为亚克力`(232, 210, 223)`，仍是方角。加大Qt遮罩、原生多边形区域或圆角区域也无法裁掉该材质。

恢复`DWMWA_WINDOW_CORNER_PREFERENCE=ROUND`后，真实屏幕角点回到桌面颜色/阴影`(155, 0, 93)`；主程序现采用这一真正生效的系统圆角。原生屏幕实测不是仅看`widget.grab()`或Qt mask。`screenshots/v1.6.11-options.png`是主窗口实际桌面抓图，`_tmp/qa_v1611/result.json`记录固定、复现旧DONOTROUND、修复、调整尺寸、最大化与还原共五个状态的窗口角点、DWM偏好和Qt遮罩状态。

亚克力外圆角受Windows系统控制，视觉半径约8px；这是为正确裁切SCA而做的取舍，不能由程序放大成自定义32px连续外轮廓。若系统圆角不可用，程序先关闭SCA亚克力，再退到32px连续曲率透明轮廓，避免错误地对亚克力矩形套Qt遮罩。最大化时清除区域；最大化还原时恢复系统裁边。清理轮廓还会显式清原生HRGN，避免Qt `clearMask()` 留下旧Win32区域。

## 加大的内部圆角与胶囊

- 普通控件连续曲率半径：8→12px。
- 卡片：12→20px；弹窗：18→26px。保持控件原有矩形尺寸和布局边距。
- 导出按钮、分段选择、滑条轨道、滚动条滑块、进度条及下载等待光带使用独立的半圆端胶囊路径。圆形状态点、单选和滑块头保持圆形；弹簧动画、原有尺寸和控件数值行为保持。
- `screenshots/v1.6.11-details.png` 左侧是主窗口实际桌面截图的局部，右侧是独立样例窗口中相同绘制实现的五种细长控件。像素测试分别核验底轨轮廓、半圆端填充、等待光带和不越出轨道的边界。
